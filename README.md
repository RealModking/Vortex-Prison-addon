# Prison Addon

A custom Minecraft Bedrock Prison Addon focused on progression, mining, enchantments, economy systems, crates, selling, and scalable prison gameplay.

---

## ✨ Features

* ⛏️ Custom prison mine system
* 🪓 Custom player pickaxes
* 📊 Blocks mined tracking
* 💰 Economy & progression systems
* 💳 Player payment system
* 🎟️ Key and token systems
* 🎁 Complete custom crate system
* 💎 GemFinder enchantment
* 🔑 KeyFinder enchantment
* 💸 AutoSell enchantment
* ⚡ Tokenator enchantment
* 🛒 Sell shop system
* 🏗️ Configurable mines
* 📦 GUI systems
* ⚙️ Server configuration support
* 🚀 Optimized for Minecraft Bedrock

---

## 🪓 Custom Pickaxe System

Every player gets a more personalized mining experience.

### Pickaxes include:

* Player name display
* Blocks mined statistics
* Custom progression systems
* Upgrade support
* Utility upgrades
* Persistent player data

## ⛏️ Mine System

The addon includes a fully customizable prison mine system.

### Features:

* Multiple mines
* Mine progression
* Mine teleport GUI
* Auto reset support
* Configurable mine sizes
* Mine management system
* Optimized mine resets
* Larger mine support in development

---

## 🎁 Crate System

Version 1.7 introduces a complete customizable crate system.

### Features:

* Create unlimited custom crates
* Add custom crate rewards
* Edit crate rewards
* Delete crate rewards
* Custom reward chances
* Reward command support
* Physical crate keys
* Scoreboard crate key support
* Automatic key overflow
* Crate preview menu
* Crate opening animations
* Crate opening sounds
* Global crate win announcements
* Improved reward saving and loading

### 🔑 Key Storage

Players can hold up to **64 physical crate keys** in their inventory.

Additional keys are automatically stored using the scoreboard system, allowing players to safely receive large quantities of keys without losing them.

---

## 🛒 Sell Shop

Version 1.7 introduces a new selling system.

### Commands:

```txt
/sell
/sell all
/sell hand
```

### Features:

* Sell items from your inventory
* Sell all supported items
* Sell the item currently in your hand
* Sell Booster support
* Raw ore support
* Smelted ingot support
* Automatic money formatting
* Large number support

### Number Formatting

The economy supports readable number formats such as:

```txt
1K
10K
100K
1M
10M
100M
1B
```

---

## 💰 Economy

### `/pay`

Players can now send money to other players using:

```txt
/pay <player> <amount>
```

### Supported Amount Formats

```txt
1K
10K
100K
1M
10M
1B
```

The economy also includes automatic money formatting for easier reading of large balances.
